# Modern Attack Chain Learning Lab

A 30-day cybersecurity learning project inspired by NetraX Cyber Conclave 2026.

This repository explores five cybersecurity problem statements through the flow:

**Identity → Network → Cloud → Application → Encryption**

## Objective

The goal is not to build production-grade offensive tools.

The goal is to understand:

- Why attacks work
- How defenders detect them
- What misconfigurations enable them
- What secure implementations look like

## Labs

| Stage | Domain | Problem Statement |
|---|---|---|
| 1 | Identity | OAuth 2.0 Token Hijacking & Scope Abuse Detection |
| 2 | Network Security | DNS Tunnelling Detection Engine |
| 3 | Cloud Security | S3 Bucket Misconfiguration Scanner & Data Exposure Detection |
| 4 | Web Security | JWT Authentication Bypass & Algorithm Confusion Attack |
| 5 | Cryptography | TLS Certificate Pinning Bypass & MitM Attack |
